# Proyecto React + Vite

Este es un proyecto creado con **React**, **Vite** y **TypeScript**.

## 🚀 Requisitos previos

Antes de comenzar, asegúrate de tener instalado lo siguiente en tu computadora:

- **Node.js** (Descargar desde [nodejs.org](https://nodejs.org/))
- **Git** (Opcional, pero recomendado. Descargar desde [git-scm.com](https://git-scm.com/))

    Para verificar que Node.js está instalado, abre la terminal y ejecuta:

    ```bash
    node -v

## Instalación

1. **Clonar el repositorio**  
   ```bash
   git clone https://github.com/Pulloc-oficial/RosaFundation.git

2. **Entrar a la carpeta**
    cd /rosa-fundation

3. **Instalar dependencias**
    npm install

4. **Iniciar el servidor de desarrollo**
    npm run dev

## Setup

1. **Crear el archivo .env**
    Crear el archivo .env con las credenciales de Firebase
